# 예외 종료 운영 확인 (#185)

- 정상 종료/고객 요청 조기 종료는 기존 최소 이용시간·실제 시간 산정 경로를 사용한다.
- 회사·파트너 사유 중단/응급 중단은 파트너가 종료 사유를 선택한다. 종료 시각만 기록하고 고객에게 운영 확인 대기를 알린다.
- 서비스 완료, 추가 청구 및 환불 원장 쓰기, 정산 승인은 DB에서 차단한다. 추가결제 승인 라우트와 환불 집행 모듈도 PG 호출 전에 보류 여부를 확인한다.
- 전체/정산 담당자는 MFA 인증 후 `/admin/service-exceptions`에서 예약번호·분류·종료 시각만 확인한다. 자유 입력 의료 메모를 목록에 반환하지 않는다.
- 현재 PR에는 예외 보류를 해제하거나 금액을 임의로 확정하는 버튼이 없다. 최신 약관의 제공 불가/부분 제공/응급 중단 금액 기준 확인 후 최종 금액 판정·환불 및 파트너 지급 원장을 연결해야 한다.
- 제공 불가의 전액 현금 환불 완료 확인 후 혜택 복원은 기존 캠페인 운영 RPC를 사용한다. 이 PR만으로 할인 행사나 혜택 복원을 실행하지 않는다.
- 최신 Notion 약관의 마지막 수정 시각과 커넥터 스냅샷이 달라 개정분을 확인하지 못했다. 정책 확인 전에는 이벤트 `active=false`, `integration_ready=false`를 유지한다.
- 마이그레이션 78의 원격 적용 및 운영 배포는 별도 진행한다. 이 PR은 예외 분류·보류 기반이므로 #185 전체 완료를 의미하지 않는다.
