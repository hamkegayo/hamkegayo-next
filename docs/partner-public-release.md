# 파트너 상세 공개 활성화 (#173)

- 사용자 2026-10-05 결정: 공개 활성화.
- /privacy 공개 안내와 /partner/profile 동의 화면을 먼저 배포하고 마이그레이션 83을 적용한다.
- 기존 별도 동의의 항목·목적·예약자 범위·매칭 중 조회 기간을 확대하지 않는다.
- 공개 플래그는 동의가 없는 파트너의 정보를 대신 공개하지 않는다. 실제 4명 파트너는 본인 프로필에서 공개 동의를 확인한다.
- 공개 정보는 관리자 검증 경력/자격만 포함한다. 임의 회원/다른 예약자/미지원 파트너 조회는 기존 RPC가 거부한다.
- 연락처·정산 계좌·증빙 원본은 비공개. 새 증빙 수집 플래그와 후기 건강정보 공개 플래그는 비활성 유지.
- 노션 정본은 읽기 전용으로 유지하며, 사이트 공개 안내 내용의 정본 반영은 담당자에게 전달한다.
