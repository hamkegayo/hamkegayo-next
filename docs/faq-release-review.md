- 위 수정안을 사용자가 확인하기 전까지 초안 PR로 유지한다. `legal-check`에 따라 FAQ를 이유로 미확정 결제·환불 정책이나 약관을 새로 확정하지 않는다.
- 2번 서울 전역 신청·서울 외 문의는 제공 문안을 반영했다. 운영팀은 실제 매칭 가능 지역을 확인해야 하며 배정을 보장하는 표현은 없다.
- 19번 변경 상담·파트너 동의는 홈페이지 자체 변경 기능을 의미하지 않는다. 운영팀의 상담 처리 절차를 확인해야 한다.
- 11번 상세 정보는 #180의 파트너 상세 기능과 함께 검토한다. #181 시간 변경과 함께 병합한 뒤 운영 안내를 확인한다.
- 서비스 원칙의 동의 범위·필요 정보 제공·가벼운 보조 범위를 구체화하고 근거 없는 모든 정보 암호화·배상 구조 확정 문구를 제거했다.
- FAQ 검색은 답변과 취소수수료 표까지 포함한다. 닫힌 답변은 키보드·스크린리더에서도 숨기며 전체/요약 화면은 동일 렌더러를 쓴다.
- 원격 DB·결제 코드·정책 원문 변경은 없다. 운영 공개 전에 수정 문안과 실제 운영 절차를 확인한다.
