# 제공 후기 등록 (#175)

- 사용자 제공 후기 PDF 3쪽의 12개 후기를 원본과 대조했다. Basic 5개·Plus 7개, 5점 10개·4점 2개다.
- 사용자 공개 요청에 따라 마이그레이션 65에 마스킹된 작성자명·제목·본문·별점·작성일을 담았다. 이는 실제 이용자 본인의 별도 공개 동의 증빙 확인을 의미하지 않는다. 실명과 원본 PDF는 커밋하지 않는다.
- 사이트 서비스 ID가 제공되지 않았으므로 `imported_reviews`에 출처를 분리한다. 가짜 회원·예약·결제를 만들지 않고 파트너 평점·실적에도 반영하지 않는다.
- `source_key` 중복 등록은 무시하며 기존 후기를 덮어쓰지 않는다. 제공 후기 수정·비공개 처리는 권한 있는 서버 운영 경로에서만 수행한다.
- 공개 RPC는 두 종류의 후기를 합쳐 최신순으로 제공하며 예약/서비스/회원 정보는 반환하지 않는다. 메인은 최신 6개, 목록·상세는 같은 데이터다.
- 근거 없는 서비스 건수 12,800건·만족도 98%와 추정 나이·관계 문구를 제거했다.
- 마이그레이션 71까지 적용하면 제공 후기 12건은 동의 증빙 미확인으로 비공개 전환한다. 다른 PR의 마이그레이션 이력과 순서를 먼저 확인한다.
- 원격 DB 적용 및 운영 공개는 이번 PR에서 수행하지 않았다. 원본의 후기 공개 동의 범위는 운영자가 보관한다.

## 검증

- #186 리뷰 보정 70은 anon/authenticated의 테이블 직접 SELECT를 회수한다. 목록·상세·메인 모두 기존 공개 RPC를 사용한다. 내부 source_key·동의 확인 시각·생성 시각은 노출하지 않는다.
- 70에서 항암·내시경 표현을 일반화했으나 71에서는 일반화 여부와 관계없이 실제 이용자의 동의 증빙 확인 전 재게시하지 않는다. 동의부터 3년 공개·만료·철회 및 허용된 항목의 공개본 검토는 docs/review-publication-consent.md에 따른다.

`scripts/test-imported-reviews.sql`은 상품·별점·마스킹·동의 미확인 비공개·쓰기 권한 차단·멱등 등록을 확인하고 롤백한다. `scripts/test-review-publication-consent.sql`은 검증된 공개본만 조회·실제 이용자/대리권·3년 만료·철회·공개 게이트를 검증한다.
