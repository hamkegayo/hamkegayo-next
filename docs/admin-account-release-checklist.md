# 관리자 계정 기능 운영 배포 체크리스트

## 배포 전

- [ ] 최초 운영 관리자 1명에게만 `전체` duty가 설정되어 있다.
- [ ] 계정 발급 담당자는 `계정`, 심사 담당자는 `심사`, 정산 담당자는 `정산`만 보유한다.
- [ ] 불필요한 `전체` 계정과 퇴사·휴직·업무변경 계정이 없다.
- [ ] 관리자 전원이 개인별 전용 계정을 사용하며 공유 계정이 없다.
- [ ] 관리자 전원이 MFA를 등록했고 복구 절차 담당자가 정해져 있다.
- [ ] `계정` 담당자는 `심사`·`정산`만, `전체` 담당자는 `계정`·`심사`·`정산`만 발급되는지 확인한다.
- [ ] `전체` duty는 관리자 UI에서 발급되지 않는지 확인한다.

## 발급 및 전달

- [ ] 임시 비밀번호는 발급 화면에서 한 번만 확인하고 저장·로그·업무 메모에 남기지 않는다.
- [ ] 승인된 메신저 또는 대면으로 수신자에게 즉시 전달한다.
- [ ] 수신자가 최초 로그인에서 비밀번호를 변경하고 MFA를 등록했는지 확인한다.
- [ ] 전달 실패·분실 시 기존 임시 비밀번호를 폐기한 뒤 사유를 입력하여 재발급한다.
- [ ] 최초 비밀번호 변경을 끝낸 계정에는 임시 비밀번호 재발급이 거절되는지 확인한다.

## 배포 후

- [ ] `계정` 또는 `전체` 담당자가 `/admin/accounts`에 접근할 수 있다.
- [ ] `심사`·`정산` 담당자는 계정 발급 화면과 RPC에 접근할 수 없다.
- [ ] 권한 부여와 임시 비밀번호 재발급 이력이 `access_logs`에 기록된다.
- [ ] 권한 부족으로 기능이 잠긴 경우 `전체` 관리자만 duty를 교정한다.
