# 후기 별도 공개 동의 운영 기준

사용자 확정: 2026-10-04. 공개 기간은 **동의일부터 3년, 이후 재동의**.

## 현재 배포 상태

- 마이그레이션 71은 운영/스테이징 DB에 아직 적용하지 않았다.
- 새 사이트 후기 원문은 작성자만 조회한다. 목록·메인·파트너 상세는 별도로 승인한 공개본만 사용한다.
- 기존 제공 후기 12건도 실제 이용자 동의 증빙을 확인한 것으로 간주하지 않는다. 71 적용 시 비공개로 전환한다. 일반화했던 2건을 포함하여 자동 재게시하지 않는다.
- 건강 정보 공개 플래그 `review_publication_release.health_enabled=false`. 전자 동의 수집 화면도 준비 상태로 유지한다.
- 노션 방침은 읽기 전용이다. 최신 개정분 확인이 불가능하여 정본 조문·시행일을 임의 수정하지 않았다. 개인정보처리방침 화면에 준비 상태와 별도 공개 안내 링크를 추가했다.

## 분리된 동의 절차

1. 후기별 실제 이용자를 확인한다. 예약자와 이용자가 다르면 예약자 체크·이메일 인증만으로 승인하지 않는다.
2. 실제 이용자의 본인 동의 증빙을 확인한다. 대리 동의는 법적 권한과 그 범위를 별도로 확인하고 증빙 참조를 기록한다. 단순 가족관계는 대리권으로 취급하지 않는다.
3. `/review/publication-consent`의 공개 목적·항목·불특정 방문자 공개 범위·3년 기간·철회 방법을 안내한다. 서비스 제공 동의와 분리한 **선택** 동의를 받는다.
4. 동의 양식에 후기 식별번호, 실제 이용자 식별 참조, 동의 주체, 정확한 공개 제목/본문, 선택한 진료·검사 종류를 개별 기재한다. 일반 후기 공개와 민감정보 공개에 각각 선택란을 둔다. 포괄적인 '건강정보 전체' 동의는 사용하지 않는다.
5. 공개본을 대조해 승인받은 항목 외의 건강 정보가 포함되지 않았는지 사람이 검토한다. 공개본과 동의 문구 버전·당시 문구 전체·동의 시각·항목·증빙을 연결한다.
6. MFA 인증한 전체 관리자만 `admin_publish_review`로 검증 결과를 등록한다. 계정 담당자·예약자·파트너는 승인할 수 없다. 직접 테이블 쓰기로 동의 정보를 바꾸지 않는다.
7. 철회 요청은 `hamkegayo@gmail.com` 또는 공개 카카오톡 문의로 받는다. 요청자 본인/대리권과 후기 식별번호를 확인하고 전체 관리자가 `admin_withdraw_review_publication`을 실행한다. 공개 RPC는 즉시 제외한다. 만료도 조회 시각에 제외한다.

## 저장 및 검증

- `review_publication_consents`: 실제 이용자 비공개 식별 참조, 본인/확인된 대리인 구분, 동의 증빙 참조, 대리권 증빙 참조, 문구 버전/스냅샷, 동의/검증 시각, 정확한 허용 항목, 만료 시각, 철회 시각/사유.
- `review_publications`: 해당 동의에 연결된 정확한 공개 제목/본문과 건강 정보 포함 여부. 운영 답변은 별도 검토 전 공개하지 않는다.
- `allowed_items`에는 `후기 공개본` 및 공개하는 구체 진료·검사 종류를 각각 기록한다. 이 목록과 공개본에 당사자가 동의했다는 증빙을 확인해야 한다.
- 증빙은 접근 제한된 보관소에 두고 DB에는 식별 참조만 기록한다. 증빙 저장소·접근 담당자·보존/파기 운영 절차는 활성화 전에 확정한다. 동의 기록이나 원본 증빙을 공용 Storage에 올리지 않는다.
- 3년 후 기존 동의 행을 갱신하지 않고 새 동의를 기록한다. 철회·만료 동의는 재사용하지 않는다.

## 방침 정본 개정안에 반영할 사항

- 처리 목적: 웹사이트 후기 공개 및 파트너 선택 참고.
- 처리 항목: 후기 공개본, 별도로 선택한 진료·검사 종류, 동의 주체와 확인 증빙, 문구 버전·시각·허용 항목·철회 상태.
- 공개 범위: 로그인하지 않은 이용자를 포함한 웹사이트 방문자. 검색·복사 가능성 안내.
- 공개 기간: 동의일부터 3년, 만료 시 중단 및 계속 공개하려면 재동의.
- 실제 이용자 본인 또는 확인된 대리권에 따른 별도 선택 동의. 서비스 동의와 분리하고 거부에 따른 서비스 불이익 없음.
- 철회: 이메일/카카오톡으로 본인·대리권 확인 후 공개 중단, 이미 복사된 정보 및 외부 검색 캐시의 한계 안내.
- 기록/증빙 보유기간과 파기 절차, 공고일·시행일 확정 후 정본 동기화. 현재 서비스 제공 목적 민감정보 동의를 웹사이트 공개 근거로 사용하지 않는다.
