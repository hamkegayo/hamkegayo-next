# 새 자격·경력 증빙 수집 고지에서 남은 내용 (#199)

현재 확인 가능한 개인정보처리방침 정본에는 새 파트너 증빙 수집의 구체적 항목과 기간이 없다. 아래 내용을 정본에 반영·확인한 후 새 업로드를 활성화한다.

1. 목적: 자격 및 의료기관/병원동행 근무 경력 심사, 허위 등록 방지.
2. 항목: 자격 종류·자격/면허번호·취득일·발급기관, 경력 유형·기관·직무·근무기간·재직 여부, 증빙 파일과 파일명/크기. 생년월일은 새로 수집하지 않는다.
3. 열람 범위: 파트너 본인 및 권한 있는 심사/전체 관리자. 고객에게 증빙 원본을 제공하지 않는다. 공개 메타정보는 별도 선택 동의 및 검증 조건을 따른다.
4. 보유기간: 사용자 확정(2026-10-05) — **최초 심사 결과 통지 후 30일**, 기간 내 진행 중인 이의신청은 처리 종료까지 필요한 자료 보관 후 파기. PR #213에서 고지·원장·자동 파기 및 기존 자료 실제 재통지로 구현한다. 검증 메타정보 및 인증 상태는 원본과 별도로 유지한다.
5. 파기: 자료·계정 삭제 시 비공개 Storage 삭제를 재시도하고, 등록에 연결되지 않은 파일은 하루 뒤 파기 대상으로 처리한다. 담당자·삭제/철회 요청 창구와 처리 절차도 안내한다.
6. 제출 주의 및 미제출 영향: 주민등록번호 뒷자리·주소를 가리고 환자/이용자 정보를 제출하지 않는다. 증빙 없이는 해당 자격/경력을 인증 완료로 표시하지 않는다. 공개 동의 거부로 예약 수락을 차단하지 않는다.

보유기간 결정은 완료됐다. 남은 항목은 PR #213 검토·배포 및 위 수집 고지의 정본 반영 확인/새 업로드 활성화다. 현재 `partner_evidence_release.enabled=false`를 유지한다.
